External API (off)
Generic OpenAI-compatible adapter. For the UpGrad API once its format is known. Mocked-HTTP tests only.

Principles that the code enforces. (1) Numbers come from tools (DuckDB, Excel data), never from the model and never from vector similarity. (2) An agent that answers without calling any tool is reminded once, then replaced by a "no tool data" message. (3) Every document-based answer cites file and page. (4) A collection is searched only after it is marked complete. (5) Nothing is deleted: old files are kept under versioned names, and the UI has no delete button.

4.1 One chat question, end to end

User types a question in the chat window (or clicks an example)

↓

UI saves the question to chats.sqlite (first question becomes the title, 48 characters)

↓

router.route(): keyword rules decide technical, fundamental, documents or both. No model.

↓

↓

Answer saved to chats.sqlite. Page reruns and shows the answer, a "Tools used" expander and the input pill.

4.2 The agent loop (same for both built agents)

Start: build the system prompt, add the question, create a Budget (12 model calls, 20 tool calls, 40,000 tokens, depth 3)

↓

Model node: gateway.chat(role="chat", messages, tools) goes to gemma4:12b through Ollama. The model returns tool calls or text.

↓

Tool calls returned
go to the tool node
Text returned, tools already used
final answer
Text returned, no tool ever used
reminder message once, then loop back to the model node. A second miss gives the fixed "no tool data" answer.

↓ tool calls

Tool node (LangGraph ToolNode): checks arguments, takes one unit from the tool budget, calls the MCP server. A bad tool name or argument goes back to the model as an error message, not a crash. Tool results are cut to 6,000 characters.

↓ tool results added to the messages, then back to the model node

Stop conditions: model-call, tool-call or token limit reached (the answer says what stopped it), or the model answers in text

4.3 A document question (RAG search at run time)

Question such as "What risks does Reliance's annual report mention?" routes to documents, so agent_fundamental runs

↓

Model node (gemma4:12b, role chat) chooses rag_search_documents(query, symbol, doc_type, year, top_k)

↓ MCP call into the fundamentals server process

Documents.search() checks the symbol, the document type and top_k (maximum 10)

↓

gateway.embed(role="embedding") turns the query into a 768-number vector with nomic-embed-text through Ollama

↓

Chroma similarity search in the complete collection ollama_local-nomic-embed-text-page-c1000-o150, filtered by symbol, type and year

↓

Score cutoff 0.65: matches below it are treated as "not found". Each kept passage is cut to 900 characters and carries file name and page.

↓ passages returned to the model node

gemma4:12b writes the answer in its own words, cites file and page, and takes no numbers from the passages. Numbers come from fsa_* tools.

4.4 Building the document index (offline, one-off)

bin/rag_build_bg.sh starts rag_build.py in the background. Log in runtime/logs/rag_build.log.

↓

Pick files per stock: all transcripts, latest 3 annual reports, latest 5 presentations (options change this). Skip files already marked done.

↓

rag_chunker.py (PyMuPDF): one chunk never crosses a page. Size 1,000 characters, overlap 150. Pages with no text are counted.

↓

gateway.embed(role="embedding") with nomic-embed-text in batches

↓

Write chunks to Chroma (one collection per embedding model and chunk setting). Record each file in rag_ingest.sqlite.

↓

When all 50 stocks are processed with no failed file, mark the collection complete. Only then does search use it.

4.5 Switching provider (no code change)

Admin view, Models panel: choose provider, model and parameters for a role. A separate "Test connection" button makes one small call to check the role. The change is saved to settings.sqlite with an audit row.

↓

Next gateway call reads the new setting. Agents and RAG code are unchanged. The key comes from an environment variable and is never stored or logged.

↓

If the embedding role changes, old vectors no longer match. A new collection must be built and finished before search switches to it. The old one is kept.

ItemDetail

Indicators computed in codeSMA, EMA, RSI, MACD, Bollinger bands, ATR
Prompt rulesAll numbers from tools. Nifty 50 only. top_movers is not the stock list (use list_stocks). State the data date once. Pass on caveats. Describe what indicators show, no promised returns, no buy or sell. Keep answers short.

5.2 agent_fundamental built, working

ItemDetail
Fileagent_fundamental.py. Subclasses TechnicalAgent and changes only the tools, the prompt and the agent name in the usage log.
ModelRole chat (gemma4:12b). The search tool also calls role embedding (nomic-embed-text) inside the MCP server.
Tools (8, from the fundamentals server) fsa_list_line_items (what a stock's workbook contains), fsa_get_financials (statement lines by section and period), fsa_get_quarterly, fsa_compute_growth (growth and CAGR), fsa_compute_ratios (margins, ROE, ROA and others), fsa_get_valuation (P/E, price to book, market cap), fsa_coverage (which stocks have which data), and rag_search_documents (annual reports, transcripts, presentations).
Prompt rulesTwo sources: statements for numbers, documents for meaning. Never quote a number that did not come from a tool. Say the unit is not stated (probably Rs crore). Do not give operating margin, interest cover or debt to equity for banks, finance companies and insurers. Cite file and page for every document point. Take no numbers from passages. Say plainly when a stock has no documents (ITC and TRENT no transcripts, BAJAJ-AUTO no presentations, INFY none).
Verified in the real UITCS CAGR 8.70%. HDFCBANK P/E 16.55x and ROE 12.97%. Reliance annual-report risks and TCS attrition from documents. ITC reported as having no transcripts.
Tests10 tests in test_agent_fundamental.py, 15 in test_fundamentals.py, 10 in test_documents.py.

5.3 agent_research_analyst stub

One-line file today. Plan: scorecard.py (code only: momentum, quality, valuation, risk, cached per stock and data date) plus an agent that writes a note around the computed numbers, with sources and data dates. It would call the technical and fundamental agents only when it needs model help.

5.4 agent_portfolio_manager stub

One-line file today. Plan: mcp_portfolio.py with validate, suggest, build (equal, inverse-volatility, risk parity, minimum variance, maximum Sharpe), metrics, sector exposure, allocate, back-test, compare, swap, rebalance, save and load. Portfolio size 4 to 6, weights 5% to 40%. Call chain: portfolio manager, then research analyst, then technical and fundamental agents (maximum depth 3, shared budget).

known defect A portfolio question, for example "Give me 2 portfolio ideas for long term and short term", currently goes to the technical agent only. It builds ideas from top_movers and get_indicators, repeats stocks across ideas and can wrongly claim "strong fundamentals". It needs a portfolio route. The first fix is a plain "portfolio building is not connected yet" reply, then the real build.
